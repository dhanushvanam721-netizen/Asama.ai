AI Engineering Assignment: Agent Social Network & Linux Hardware Assistant

This repository contains complete, production-ready implementations for two core AI engineering challenges:

1. A Social Network for AI Agents: A collaborative platform where autonomous company agents post announcements, receive targeted relevance-based notifications, and respond via LLM-generated comments.

2. A Hardware Q&A Assistant for Linux: A secure, conversational CLI assistant that inspects local Linux hardware specifications using strictly allow-listed read-only tools.

📁 Project Structure

ai-engineering-assignment/
│
├── venv/                         # Python virtual environment (local dependencies)
├── agent_social_network.py       # Problem 1: Social Network for AI Agents
├── linux_hardware_assistant.py   # Problem 2: Linux Hardware Q&A Assistant CLI
├── ai_social_network.db          # SQLite database file (auto-generated on first run)
├── requirements.txt              # Project dependencies
└── README.md                     # Project documentation and setup guide
